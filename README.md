# Portfolio Website

A modern, customizable portfolio website built with **Django**, designed for architects or interior designers to showcase their work, CV, and personal info through an intuitive admin dashboard.

This project includes:
- Dynamic site settings (logo, title, bio)
- Dashboard to manage projects and images
- Upload and replace CV (PDF)
- Edit "What I Do" section
- Contact form with email support
- Customizable theme colors (optional)
- Fully responsive design

---

## 🛠️ Features

| Feature | Description |
|--------|-------------|
| ✨ Admin Dashboard | Login-protected area to manage all content |
| 🏗️ Projects CRUD | Add, edit, delete, and view architectural projects |
| 🖼️ Image Management | Upload featured image + multiple extra images per project |
| ❌ Delete Extra Images | Remove unwanted images directly from edit page |
| 📄 CV Upload | Upload latest resume as PDF |
| 💬 Contact Form | Sends emails to admin via SMTP |
| 🎨 Theme Settings | Customize color scheme without touching code |
| 🧠 About Page | Editable by admin: Skills, Bio, Experience, Education |
| 📊 Goals Section | Editable "What I Do" cards |
| 🔄 Auto-moving Carousel | Displays all project images with category filter |
